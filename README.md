# IFA 展區重新分類專案

## 專案說明

本專案針對111家台灣廠商進行IFA展區重新分類，採用更嚴格的分類標準，明確區分消費性電子產品與OEM/ODM供應商產品，並標示不符合展區的公司。

## 檔案說明

### 主要檔案
- **reclassified_ifa_zones.csv** - 完整的重新分類結果（包含111家公司及分類說明）
- **zone_statistics.md** - 各展區統計數據與公司列表
- **zone_changes_summary.txt** - 主要變更摘要（快速參考）

### 說明文件
- **reclassification_summary.md** - 分類原則與方法論說明
- **classification_changes.md** - 原始分類與新分類的詳細對比表

## 主要變更重點

### ⭐ 問題核心
**旭陽國際精機股份有限公司**（序號47）
- 產品：馬達（CNC相關）
- 原分類：智慧居家館 ❌
- 新分類：無符合展區 ✓
- 理由：工業馬達不符合消費性電子展覽定位

### 分類結果統計

| 展區 | 公司數 | 占比 |
|------|--------|------|
| IFA Global Markets | 72 | 64.9% |
| IFA Next | 15 | 13.5% |
| 無符合展區 | 12 | 10.8% |
| 健身健康裝置專區 | 4 | 3.6% |
| 電子移動館 | 3 | 2.7% |
| 大眾通訊館 | 3 | 2.7% |
| 智慧居家館 | 1 | 0.9% |
| 家庭用品館 | 1 | 0.9% |

### 核心分類原則

1. **終端消費產品** → 對應消費展區
   - 家庭用品、健身設備、智慧家居終端產品等

2. **OEM/ODM供應商** → IFA Global Markets
   - 電子元件、模組、半導體、電源、測量儀器等

3. **工業設備/醫療軟體** → 無符合展區
   - 工業馬達、變壓器、測試設備、醫療診斷軟體等

4. **新創與創新技術** → IFA Next
   - AI、IoT、創新科技（排除傳統測量儀器等成熟產品）

## 主要調整類別

### 1. 從「智慧居家館」移出（14家 → 1家）
- 移至「無符合展區」：6家（工業設備、醫療軟體）
- 移至「IFA Global Markets」：6家（OEM/ODM供應商）
- 移至其他展區：1家

### 2. 「IFA Next」更嚴格篩選（25家 → 15家）
- 將傳統測量儀器、電源供應器等成熟產品移至 IFA Global Markets

### 3. OEM/ODM供應商統一歸類（53家 → 72家）
- 統一將電子元件、模組、半導體供應商歸入 IFA Global Markets

### 4. 新增「無符合展區」（12家）
- 工業設備、醫療軟體、B2B服務等不適合消費性電子展

## 使用方式

1. 查看 **reclassified_ifa_zones.csv** 獲取完整的重新分類結果
2. 閱讀 **zone_changes_summary.txt** 快速了解主要變更
3. 參考 **zone_statistics.md** 查看各展區的詳細公司列表
4. 查閱 **classification_changes.md** 了解每個變更的詳細對比
