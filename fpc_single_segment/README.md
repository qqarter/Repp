Single-segment FPC design package for WS2812B-4020 (5-LED segment)

This folder contains the design specification, BOM, manufacturing notes, pad coordinates and assembly instructions for the FPC single-segment intended to fit into the provided case geometry.

Files included:
- fpc_pad_coords.csv — LED center coordinates and board length
- footprint_spec.txt — pad / footprint notes (WS2812B side-mount)
- bom_fpc_single_segment.csv — BOM suggestions
- manufacturing_notes.txt — instructions for FPC vendor
- assembly_instructions.md — assembly/testing guidance

Use these files to generate Gerbers and STEP. Final Gerber/STEP ZIP will be added to this folder when available.
